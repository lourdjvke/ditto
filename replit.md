# Bang & Olufsen Clone

A static Next.js 15 (App Router) clone of the Bang & Olufsen homepage, generated by ditto.site from the live B&O site.

## Stack
- **Framework**: Next.js 15 with App Router
- **Styling**: Tailwind CSS v4 + `ditto.css` for fidelity overrides
- **Language**: TypeScript

## Running the app
The app lives in `bang-olufsen-clone/project/`.

```bash
cd bang-olufsen-clone/project
npm install
npm run dev
```

On Replit the workflow `artifacts/bo-clone: web` handles this automatically using the `$PORT` environment variable.

## Project layout
- `src/app/page.tsx` — homepage route
- `src/app/components/` — reusable JSX components
- `src/app/sections/` — page sections
- `src/app/svgs/` — inline SVG modules
- `src/app/ditto.css` — fidelity CSS (pseudo-elements, keyframes, interaction states)
- `src/app/content.ts` — editable structured content extracted from repeated regions
- `src/app/ditto/` — generated runtime utilities (DropdownMenu); do not edit casually
- `public/assets/cloned/` — materialized source assets

## Safe edit areas
- `src/app/content.ts` — copy and structured data
- `src/app/components/` — JSX structure and copy
- `src/app/sections/` — section-level layout
- `src/app/ditto.css` — minor visual tweaks (broad rewrites can break fidelity)
