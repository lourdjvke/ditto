# Bang & Olufsen Clone

A high-fidelity static Next.js 15 clone of the Bang & Olufsen website, generated by ditto.site and enhanced with interactive React components.

## Stack
- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4 + custom design tokens in `globals.css` / `ditto.css`
- **React**: 19
- **Build output**: Static export (`output: "export"` → `out/` directory)

## Running locally (Replit)
The `artifacts/bo-clone: web` workflow runs:
```
cd /home/runner/workspace/bang-olufsen-clone/project && npm run dev -- -H 0.0.0.0 -p $PORT
```

## Key source locations
- `src/app/sections/navbar.tsx` — shared navbar (transparent → white on scroll, sidebar z-1000)
- `src/app/sections/footer.tsx` — shared footer
- `src/app/en/int/earphones/beograce/` — Beo Grace page + custom carousels
  - `components/AdaptiveChargingCarousel.tsx` — charging section carousel
  - `components/LeatherCaseCarousel.tsx` — leather case with color swatches
  - `components/BeoGraceFullscreenCarousel.tsx` — hero carousel fullscreen modal
- `src/app/en/int/story/about-bang-and-olufsen/components/feature-card.tsx` — interactive FAQ accordion
- `public/assets/cloned/` — all local images, SVGs, and videos

## Cloudflare Pages deployment
