# Bang & Olufsen Clone

A static Next.js App Router clone of bang-olufsen.com, generated by ditto.site. It captures the rendered DOM, CSS, assets, fonts, and interaction recipes from the live site.

## Stack

- **Framework**: Next.js 15 (App Router)
- **Styling**: Tailwind CSS v4 + `ditto.css` for fidelity overrides
- **Language**: TypeScript

## Running the app

```bash
cd bang-olufsen-clone/project
npm install
npm run dev
```

The app is configured as the `artifacts/bo-clone` artifact and runs via the `artifacts/bo-clone: web` workflow.

## Project structure

- `bang-olufsen-clone/project/src/app/` — Next.js app directory (pages, components, sections, SVGs)
- `bang-olufsen-clone/project/src/app/content.ts` — Editable structured content layer
- `bang-olufsen-clone/project/src/app/ditto.css` — Fidelity CSS (layout, pseudo-elements, keyframes)
- `bang-olufsen-clone/project/src/app/ditto/` — Runtime utilities (DropdownMenu); do not edit casually
- `bang-olufsen-clone/project/public/assets/cloned/` — Materialized fonts and images from the source site

## Safe edit areas

- `src/app/content.ts` — copy, links, and structured data
- `src/app/components/` — JSX component modules
- `src/app/sections/` — page section modules
- `src/app/ditto.css` — small visual tweaks are fine; broad rewrites can break fidelity
